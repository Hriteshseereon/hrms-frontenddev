Generated by `tools/gen_api_docs.py` from the running code (do not edit by hand). Base URL: `/api/v1`. Interactive docs: `/docs` (Swagger) and `/redoc`; machine-readable contract: `docs/openapi.json`.

**850 operations** across **86 screens**.

## Conventions

- **Auth**: `POST /auth/login` → `accessToken` (JWT, 15 min) + `refreshToken` (rotating, 7 days). Send `Authorization: Bearer <accessToken>`; refresh with `POST /auth/refresh`.
- **Working scope**: Super Admin / Admin send `X-Company-Id` (and optionally `X-Branch-Id`). Without a company a group Super Admin works in the read-only collective view.
- **Errors**: RFC 7807 `application/problem+json` — `{title, status, detail, code, errors[{field,message}]}`. 422 business rule, 403 permission, 404 not found, 409 state conflict, 412 stale version, 423 period locked.
- **Lists**: `?page=&pageSize=&q=&sort=` → `{items, total, page, pageSize}`.
- **Writes**: optional `Idempotency-Key` header on POST; `If-Match` with the record's ETag on PUT/PATCH.
- **Files**: upload with `POST /files` (multipart) and send the returned ids in forms.
- **Wire format**: camelCase JSON; money is a JSON number (Decimal server-side); dates ISO `YYYY-MM-DD`.
